# Стиль кодирования

[English](./coding-style.md) | Русский

Этот документ определяет стандарты кодирования для проекта.
Этот стандарт разработан для стиля кода Java.

## Соглашения о файлах

- Стандартное расширение файлов для файлов Java - это `java`.
- Название файла должно точно соответствовать названию основной сущности.
- Файлы должны быть сохранены в кодировке __UTF-8__ с окончанием строк __LF__ и должны заканчиваться одной пустой строкой.

## Соглашения об именовании

- Названия пакетов должны быть в единственном числе и в __Lower Case__.
- Название класса или интерфейса должно быть написано в __Pascal Case__.
  - Интерфейс должен иметь префикс `I`.
  - Тестовый класс должен иметь постфикс `Test`.
- Названия констант должны быть написаны заглавными буквами в __Snake Case__.
- Названия переменных и методов должны быть в __Camel Case__.
  - Методы событий должны иметь префикс `on`, затем название события и приоритет.

## Форматирование кода

- Не более 120 символов в строке.
- Используйте 4 пробела вместо табуляций.
- Используйте фигурные скобки для обозначения условий и циклов.
- Фигурные скобки должны быть на новой строке.
- Используйте 1 пробел между ключевым словом и условием.

## Рекомендации

- Используйте правила группировки и разделяйте импорты:
  - Стандартная Java (`java.*`, `javax.*`).
  - Зависимости (`org.springframework.*`).
  - Проектно-специфичные (`org.imesense.*`).
- Используйте одну пустую строку между группами импортов.
- Указывайте `final` в окончательной реализации классов, если нет абстрактных и переопределённых методов.
- Классы с методами, помеченными как `@SubscribeEvent`, должны иметь аннотацию `@Mod.EventBusSubscriber`.
- Используйте аннотацию `@Unique` многократного использования полей вместо дубликатов.
